## 宿題

- 取り組んだレベルは **基礎**。
- `app/config.py` の `RAG_TOP_K` を `5` から `3` に変更した。1回の検索で渡すページを減らし、回答に必要な根拠が残るかを確かめる。
- 比較した質問は「第2回の説明では、LoRAは何を固定し何を学習しますか？ QLoRAは何を加えますか？」。Codespaces で回答モデル `gemini-3.5-flash-lite`、埋め込みモデル `gemini-embedding-001`、同梱の第1〜3回本講義214ページの検索DBを使い、5件、3件の順でそれぞれ1回ずつ実行した。

### Geminiでの実測

| `--trace` の確認項目 | 変更前（上位5件） | 変更後（上位3件） |
|---|---|---|
| `search_materials` の `query` | `LoRA 固定 学習 QLoRA 加える` | `LoRA QLoRA 固定 学習` |
| ツール呼び出し回数 | 1回 | 1回 |
| 検索結果の先頭 | 第2回・PDF p.52 | 第2回・PDF p.52 |
| 回答が引用したページ | 第2回・PDF p.51、52 | 第2回・PDF p.51、52 |
| 回答完了まで | 3.69秒 | 3.01秒 |
| 入力／出力トークン数 | 3,028／185 | 2,077／173 |
| モデル応答回数 | 2回 | 2回 |
| 生成API推定費用 | 0.001371 USD | 0.001056 USD |

どちらも、LoRAは元の重みを固定し、行列A・Bの積で表す低ランクの差分を学習すると答えた。QLoRAについては元の重みを4ビットに量子化すると答えた。引用先を確認すると、p.51は比較図でLoRAとQLoRAの違いを示し、p.52は固定する重みと学習する行列を図で説明していた。

3件にした回では、入力が951トークン（31.4%）、生成API推定費用が0.000315 USD（23.0%）減った。時間は埋め込みと検索を含み、費用は回答生成分の推定値。

### 気づき・疑問

この質問では、答えに必要な根拠が上位3件に収まった。同じ質問でもモデルが作った検索語が異なり、各条件1回なので、件数変更だけで時間や費用がどれだけ変わるかは判断できない。複数ページに答えが分かれる質問では、必要なページが4位以下に落ちる場合も確かめたい。

同じ入力ベクトルで件数の違いも確認した。p.52の保存済みベクトルを使ったローカル検証では、5件でp.52、51、60、61、11、3件でp.52、51、60が返り、ツール結果のJSONは4,208文字から2,635文字に減った。この検証の検索順位は、Geminiで質問を埋め込んだときの順位とは条件が異なる。
